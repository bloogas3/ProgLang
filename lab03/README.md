Тип в программировании — набор допустимых значений и операций над ними. Например, int хранит целые числа, которые можно складывать и сравнивать.
Статическая типизация — типы проверяются до выполнения программы, при трансляции. Например, в C++ переменная int не становится строкой.
Динамическая типизация — тип относится к объекту и проверяется во время выполнения. В Python имя сначала можно связать с числом, затем со строкой.
Неявная типизация — тип не указывается прямо, а выводится из выражения. Например, auto x = 5; в C++ даёт int. Тип x определяется при компиляции и дальше не меняется.
Явное преобразование типа — программист сам записывает преобразование. Например, static_cast<double>(5) или int("5") в Python.
Неявное преобразование типа — преобразование выполняется по правилам языка без специальной записи. Например, double x = 5; в C++.
Сильная типизация — язык строже ограничивает смешивание разных типов. Например, Java не разрешает складывать boolean и int.
Слабая типизация — язык допускает больше автоматических преобразований. Например, C++ разрешает true + 2 и получает 3.

### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

*Проверка отчета будет включать проверку знания правил.*

*Преобразования при присваивании*

При присваивании значение справа преобразуется к типу переменной слева.

```cpp
double a = 5;    // int преобразуется в double: 5.0
int b = 3.8;     // дробная часть отбрасывается: 3
int c = -3.8;    // получается -3
```

При преобразовании вещественного числа в целое дробная часть отбрасывается, а не округляется. Полученное целое должно помещаться в целевой тип.

*Преобразования при арифметических действиях*

Перед арифметическими действиями значения типов `bool`, `char`, `short` и `unsigned short` обычно преобразуются в `int`. Если `int` не вмещает все значения исходного типа, используется `unsigned int`.

```cpp
short a = 10, b = 20;
auto c = a + b;  // тип c — int
```

Если один операнд целый, а другой вещественный, целый преобразуется в вещественный тип.

```cpp
int a = 5;
double b = 2.0;
double c = a / b;  // 2.5
```

Если оба операнда целые, деление будет целочисленным. Тип переменной, в которую записывается результат, этого не меняет.

```cpp
double a = 5 / 2;  // сначала получается 2, затем 2.0
```

При смешивании вещественных типов выбирается `long double`, если он есть среди операндов, иначе `double`, иначе `float`.

Для целых типов после повышений действуют следующие правила:

- При одинаковой знаковости выбирается тип большего ранга: `int`, затем `long`, затем `long long`.
- Если ранг беззнакового типа не меньше ранга знакового, выбирается беззнаковый тип.
- Если ранг знакового больше и он вмещает все значения беззнакового, выбирается знаковый тип.
- Иначе выбирается беззнаковый вариант знакового типа большего ранга.

Например, при операции между `int` и `unsigned int` общий тип — `unsigned int`.

*Преобразования с логическими значениями*

При преобразовании числа в `bool` ноль становится `false`, а любое ненулевое значение — `true`.

```cpp
bool a = 0;   // false
bool b = 5;   // true
bool c = -2;  // true
```

При преобразовании `bool` в число `false` становится `0`, а `true` — `1`.

```cpp
int a = false;         // 0
int b = true;          // 1
int c = true + true;   // 2
```

В условиях `if`, `while` и в логических операциях числа тоже проверяются как логические значения.

```cpp
int n = 3;

if (n) {
    std::cout << "n is not zero";
}
```

### Задание 5. **(2)**

*Приведите разумные (логичные) примеры использования в 
С++ ключевых слов* **typedef, auto, decltype, static_cast** и оператора **sizeof**.

*Записанные программы сохраните в папке с номером задания. В отчет запишите пояснения к программам*.
```cpp
#include <iostream>
#include <vector>

int main() {
    typedef std::vector<int> Marks;
    Marks marks = {4, 5, 3, 5};

    int sum = 0;

    for (auto it = marks.begin(); it != marks.end(); ++it) {
        sum += *it;
    }

    decltype(sum) total = sum;

    double average = static_cast<double>(total) / marks.size();

    std::cout << "Sum: " << total << std::endl;
    std::cout << "Average: " << average << std::endl;
    std::cout << "One mark takes "
              << sizeof(marks[0]) << " bytes" << std::endl;

    return 0;
}
```

В программе вычисляется среднее значение оценок.

- `typedef` создаёт короткое имя `Marks` для типа `std::vector<int>`. Это другое имя уже существующего типа.
- `auto` определяет тип итератора по выражению `marks.begin()`. Благодаря этому не нужно писать `std::vector<int>::iterator`.
- `decltype(sum)` позволяет объявить `total` с тем же типом, что и `sum`. Здесь это `int`.
- `static_cast<double>(total)` преобразует сумму в `double`, чтобы деление было вещественным. Без преобразования получилось бы `4`, а нужно `4.25`.
- `sizeof(marks[0])` показывает размер одной оценки в байтах. Поскольку оценка имеет тип `int`, результат равен `sizeof(int)`.

На компьютере с четырёхбайтовым `int` получится:

```text
Sum: 17
Average: 4.25
One mark takes 4 bytes
```

Размер `int` зависит от платформы.

* *Что произойдет, если тип* **int** *заменить на* **short**, а **unsigned int** на **unsigned short**?*
В выражении `a * b` обе переменные имеют тип `int`. Поэтому результат равен `-1`.

В выражении `a * c` участвуют `int` и `unsigned int`. Перед умножением значение `a` преобразуется в `unsigned int`.

При 32-битном `unsigned int` число `-1` превращается в `4294967295`. После умножения на `1` получается то же значение.

Вывод в этом случае:

```text
-1
4294967295
```

После замены типов программа будет такой:

```cpp
#include <iostream>

int main() {
    short a = -1, b = 1;
    unsigned short c = 1;

    std::cout << a * b << std::endl;
    std::cout << a * c << std::endl;

    return 0;
}
```

На обычной платформе с 16-битным `short` и 32-битным `int` перед умножением все операнды преобразуются в `int`, потому что он вмещает весь диапазон `short` и `unsigned short`.

Поэтому вывод будет:

```text
-1
-1
```

Если на другой платформе `int` не вмещает все значения `unsigned short`, переменная `c` повысится до `unsigned int`. Тогда второе произведение снова будет беззнаковым.

### Задание 7 **(2)**
*Рассмотрите следующий фрагмент программы.*
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
*Почему изменения порядка действий приводит
к изменению результата? Объясните работу этой программы, используя правила неявного преобразования типов*

В выражении `(x / y) / d` сначала выполняется `7 / 4`. Обе переменные целые, поэтому получается `1`. Затем это значение преобразуется в `long double` и делится на `0.25`.

```text
(7 / 4) / 0.25 = 1 / 0.25 = 4
```

В выражении `(x / d) / y` сначала число `7` преобразуется в `long double`. Поэтому первое деление уже вещественное.

```text
(7 / 0.25) / 4 = 28 / 4 = 7
```

Таким образом, первые две строки вывода:

```text
4
7
```

Результаты отличаются, потому что в первом выражении дробная часть теряется при целочисленном делении.

В выражении `(a * b) * c` сначала перемножаются два значения типа `long`:

```text
200000 * 200000 = 40000000000
```

Если `long` занимает 32 бита, это число в него не помещается. Происходит переполнение знакового типа, и поведение программы становится неопределённым. Нельзя заранее указать надёжный результат этого выражения.

Последующее умножение на `long long` не исправляет переполнение, которое уже произошло.

В выражении `a * (b * c)` сначала перемножаются `long` и `long long`. Значение `b` преобразуется в `long long`, поэтому промежуточный результат помещается в тип. Затем `a` тоже преобразуется в `long long`.

Получается:

```text
8000000000000000
```

Если `long` занимает 64 бита, оба порядка умножения дают правильный результат.

Чтобы первый вариант работал и при 32-битном `long`, нужно преобразовать операнд до первого умножения:

```cpp
std::cout << static_cast<long long>(a) * b * c << std::endl;
```

### Задание 9 **(2)**

*Проверьте работу логического выражения*
```
x==y==z
```
*в языках* **Python**, **Java**, **C++** *для
целочисленных переменных* **x**, **y**, **z**.
*Объясните результат для каждого из языков.*

*Записанную программу сохраните в папке с номером задания.*

Выражения `x == y` и `x == z` имеют тип `bool`. При сложении они преобразуются в `int`: `false` становится `0`, а `true` — `1`.

Значение `true` справа тоже преобразуется в `1`. Поэтому всё выражение проверяет, равна ли сумма результатов сравнений единице.

Все варианты:

| Условия | Сумма | Результат |
|---|---|---|
| `x != y` и `x != z` | `0 + 0 = 0` | `false` |
| `x == y` и `x != z` | `1 + 0 = 1` | `true` |
| `x != y` и `x == z` | `0 + 1 = 1` | `true` |
| `x == y` и `x == z` | `1 + 1 = 2` | `false` |

В первой строке значения `y` и `z` могут быть как равными, так и разными.

Ответ: выражение истинно только тогда, когда `x` равен ровно одной из переменных `y` и `z`.

Программа для проверки:

```cpp
#include <iostream>

int main() {
    int examples[4][3] = {
        {2, 3, 4},
        {2, 2, 3},
        {2, 3, 2},
        {2, 2, 2}
    };

    std::cout << std::boolalpha;

    for (int i = 0; i < 4; ++i) {
        int x = examples[i][0];
        int y = examples[i][1];
        int z = examples[i][2];

        bool result = ((x == y) + (x == z) == true);

        std::cout << x << " " << y << " " << z
                  << " -> " << result << std::endl;
    }

    return 0;
}
```

Результат:

```text
2 3 4 -> false
2 2 3 -> true
2 3 2 -> true
2 2 2 -> false
```

### Задание 9 **(2)**

**Python**

```python
examples = [
    (2, 2, 2),
    (2, 2, 1),
    (2, 3, 0)
]

for x, y, z in examples:
    print(x, y, z, "->", x == y == z)
```

Результат:

```text
2 2 2 -> True
2 2 1 -> False
2 3 0 -> False
```

В Python выражение `x == y == z` является цепочкой сравнений. Для целых переменных оно означает то же самое, что `(x == y) and (y == z)`. Результат истинен, только если все три числа равны.

**C++**

```cpp
#include <iostream>

int main() {
    int examples[3][3] = {
        {2, 2, 2},
        {2, 2, 1},
        {2, 3, 0}
    };

    std::cout << std::boolalpha;

    for (int i = 0; i < 3; ++i) {
        int x = examples[i][0];
        int y = examples[i][1];
        int z = examples[i][2];

        std::cout << x << " " << y << " " << z
                  << " -> " << (x == y == z) << std::endl;
    }

    return 0;
}
```

Результат:

```text
2 2 2 -> false
2 2 1 -> true
2 3 0 -> true
```

В C++ выражение вычисляется как `(x == y) == z`.

Сначала получается `true` или `false`. Затем этот результат преобразуется в `1` или `0` и сравнивается с `z`.

Поэтому выражение истинно в двух случаях:

- `x == y` и `z == 1`;
- `x != y` и `z == 0`.

Для проверки равенства всех трёх чисел нужно написать:

```cpp
(x == y) && (y == z)
```

**Java**

```java
public class Main {
    public static void main(String[] args) {
        int x = 2, y = 2, z = 2;
        System.out.println(x == y == z);
    }
}
```

Программа не компилируется.

Сначала выражение `x == y` даёт значение типа `boolean`. Затем программа пытается сравнить его с целым числом `z`. В Java сравнение `boolean` и `int` через `==` запрещено.

Правильная проверка равенства всех трёх чисел:

```java
System.out.println((x == y) && (y == z));
```

При `x = 2`, `y = 2`, `z = 2` исправленный вариант выведет `true`.
