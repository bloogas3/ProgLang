- *Запишите двоичное представление числа -99 в целочисленном знаковом типе длиной 1, 2, 4 байта.*
- *Запишите литералы равные наибольшему и наименьшему числу в типе* **int** *в шестнадцатеричной записи.*
- *Запишите двоичное представление символа "`#`" в типе* **char**.

## Решение

### 1. Двоичное представление числа `-99`

Сначала переведем число `99` в двоичную систему:

```text
99 = 64 + 32 + 2 + 1
99 = 01100011₂
```

Для получения отрицательного числа используется дополнительный код.

Инвертируем биты:

```text
01100011
10011100
```

Прибавляем `1`:

```text
10011100
       1
--------
10011101
```

Получаем:

```text
1 байт:
10011101
```

При увеличении длины отрицательного числа выполняется знаковое расширение, поэтому слева добавляются единицы:

```text
2 байта:
11111111 10011101
```

```text
4 байта:
11111111 11111111 11111111 10011101
```

Итого:

```text
1 байт:  10011101

2 байта: 11111111 10011101

4 байта: 11111111 11111111 11111111 10011101
```

### 2. Наибольшее и наименьшее значения `int`

Будем считать, что `int` имеет длину 32 бита.

Диапазон знакового 32-битного типа:

```text
-2³¹ ... 2³¹ - 1
```

То есть:

```text
-2147483648 ... 2147483647
```

Максимальное значение:

```text
01111111 11111111 11111111 11111111
```

В шестнадцатеричной записи:

```text
0x7FFFFFFF
```

Минимальное значение имеет двоичный код:

```text
10000000 00000000 00000000 00000000
```

Его шестнадцатеричное представление:

```text
0x80000000
```

Таким образом:

```text
INT_MAX = 0x7FFFFFFF

INT_MIN имеет 32-битный код 0x80000000
```

Корректно записать значение минимального `int` в выражении C++ можно так:

```cpp
-0x7FFFFFFF - 1
```

# Задание 2 **(3)**

*Напишите пример программы на С++ с использованием целочисленных литералов в разных форматах записи, разной длины, знаковых и беззнаковых. Пример должен охватывать большинство способов записи целочисленных литералов.*

## Решение

```cpp
#include <iostream>

int main() {
    int decimal = 42;                   // десятичная запись
    int octal = 052;                    // восьмеричная запись
    int binary = 0b101010;              // двоичная запись
    int hexadecimal = 0x2A;             // шестнадцатеричная запись

    int negative = -42;                 // отрицательное число

    unsigned int u = 42U;               // unsigned
    long int l = 42L;                   // long
    long long int ll = 42LL;            // long long

    unsigned long int ul = 42UL;         // unsigned long
    unsigned long long int ull = 42ULL; // unsigned long long

    unsigned long long int value = 0xA0ULL;

    std::cout << decimal << std::endl;
    std::cout << octal << std::endl;
    std::cout << binary << std::endl;
    std::cout << hexadecimal << std::endl;
    std::cout << negative << std::endl;
    std::cout << u << std::endl;
    std::cout << l << std::endl;
    std::cout << ll << std::endl;
    std::cout << ul << std::endl;
    std::cout << ull << std::endl;
    std::cout << value << std::endl;

    return 0;
}
```

Использованные способы записи:

```text

0x2A        — шестнадцатеричная запись

42U         — unsigned
42L         — long
42LL        — long long
42UL        — unsigned long
42ULL       — unsigned long long
```

Все четыре записи:

```text

0b101010
0x2A
```

представляют одно и то же значение:

```text

```

Например:
10:25
```cpp
0xA0ULL
```

означает:

```text

```

# Задание 3 **(2)**

*Объясните работу фрагмента программы на С++. В ходе объяснения следует использовать таблицу кодов символов.*

```cpp
char a = 'a';
a = a + 10;
std::cout << a;
a = a + 250;
std::cout << a;
```

## Решение

В таблице ASCII символ `'a'` имеет код:

```text
'a' = 97
```

После:

```cpp
a = a + 10;
```

получаем:

```text
97 + 10 = 107
```

В таблице ASCII код `107` соответствует символу:

```text
'k'
```

Поэтому первый `cout` выводит:

```text
k
```

Далее значение `a` равно `107`.

Выполняется:

```text
107 + 250 = 357
```

Тип `char` занимает один байт, то есть 8 бит.

Количество различных 8-битных комбинаций:

```text
2⁸ = 256
```

В рамках модели из лекции получаем значение по модулю `256`:

```text
357 mod 256 = 101
```

В ASCII код `101` соответствует символу:

```text
'e'
```

Следовательно, программа выводит:

```text
ke
```

97 + 10 = 107

chr(107) = 'k'

```text
ord('k') = 107
```

107 + 250 = 357
```

chr(357)

и получается Unicode-символ:

ť

kť

ke

# Задание 5 **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* `x+x−x=x`, *но при этом* `(x⋅2)/2≠x`? *В отчете надо привести вычисления, приводящие к ответу.*

```cpp
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```

## Решение

Будем считать, что:

```text
unsigned short = 16 бит
```

Диапазон:

```text
0 ... 2¹⁶ - 1
```

```text
0 ... 65535
```

Также:

```text
2¹⁶ = 65536
```

Изначально:

```text
x = 40000
```

### Вычисление `y`

```text
x + x = 40000 + 40000
      = 80000
```

Число `80000` не помещается в `unsigned short`.

Поэтому:

```text
80000 mod 65536
= 80000 - 65536
= 14464
```

Получаем:

```text
y = 14464
```

Далее:

```cpp
y = y - x;
```

```text
14464 - 40000 = -25536
```

При сохранении результата в `unsigned short`:

```text
-25536 mod 65536 = 40000
```

Получаем:

```text
y = 40000
```

---

### Вычисление `z`

```text
x * 2 = 40000 * 2
      = 80000
```

После записи в `unsigned short`:

```text
80000 mod 65536 = 14464
```

Получаем:

```text
z = 14464
```

Далее:

```cpp
z = z / 2;
```

```text
14464 / 2 = 7232
```

Получаем:

```text
z = 7232
```

Итоговый вывод:

```text
40000 7232
```

Причина различия заключается в том, что при умножении на `2` возникает переполнение и старшие биты теряются.

При последующем делении они уже не могут восстановиться.

Для `y`:

```text
40000 + 40000 -> 14464
14464 - 40000 -> 40000
```

Для `z`:

```text
40000 * 2 -> 14464
14464 / 2 -> 7232
```

Поэтому:

```text
x + x - x = x
```

но:

```text
(x * 2) / 2 != x
```

# Дополнительное задание 2 **(3)**

*Какие значения можно присвоить целочисленной переменной* **x**, *чтобы результатом выражения `x&(x-1)` стало число 0? Найдите все значения без использования компьютерных вычислений (среди них есть отрицательные числа). Обоснуйте ответ.*

## Решение

Если положительное число является степенью двойки, его двоичная запись содержит ровно одну единицу.

Например:

```text
x = 8 = 1000₂
```

Тогда:

```text
x - 1 = 7 = 0111₂
```

Операция `&`:

```text
1000
0111
----
0000
```

Поэтому подходят все положительные степени двойки:

```text
1, 2, 4, 8, 16, 32, ...
```

Также подходит:

```text
x = 0
```

так как в модели фиксированной длины:

```text
0 & (-1) = 0
```

Теперь рассмотрим минимальное отрицательное число знакового типа:

```text
-2^(n-1)
```

Его двоичный дополнительный код:

```text
1000...000
```

В рамках арифметики фиксированной длины:

```text
x - 1 = 0111...111
```

Тогда:

```text
1000...000
0111...111
-----------
0000...000
```

Следовательно, минимальное отрицательное число типа также является решением.

В общем виде:

```text
x = 0
```

или:

```text
x = 2^k
```

для положительных степеней двойки, либо:

```text
x = -2^(n-1)
```

Для 32-битного типа:

```text
0,
1,
2,
4,
8,
16,
...
1073741824,
-2147483648
```

# Дополнительное задание 3 **(3)**

# Дополнительное задание 4 **(3)**

*Обоснуйте корректность работы программы "Разложение числа по степеням двойки" из лекции. Требуется определить, что будет результатом выражения `x&-x`.*

## Решение

Для отрицательного числа в дополнительном коде:

```text
-x = ~x + 1
```

Пусть число имеет вид:

```text
x = ...1011000
```

Инвертируем его:

```text
 x = ...1011000
~x = ...0100111
```

Прибавляем единицу:

```text
-x = ...0101000
```

Теперь выполняем:

```text
x & -x
```

```text
 x = ...1011000
-x = ...0101000
---------------
     ...0001000
```

В результате остается только младший установленный бит числа `x`.

Следовательно:

```text
x & -x
```

возвращает степень двойки, соответствующую младшей единице двоичной записи числа.

Например:

```text
x = 12 = 1100₂
```

```text
x & -x = 0100₂ = 4
```

Рассмотрим программу:

```cpp
while (x > 0) {
    int t = x & -x;
    std::cout << '+' << t;
    x -= t;
}
```

На каждой итерации:

```text
t = x & -x
```

находит младшую степень двойки, содержащуюся в числе.

После:

```text
x -= t
```

эта единица удаляется.

Например:

```text
x = 13 = 1101₂
```

Первая итерация:

```text
13 & -13 = 1
```

```text
13 - 1 = 12
```

Вторая:

```text
12 & -12 = 4
```

```text
12 - 4 = 8
```

Третья:

```text
8 & -8 = 8
```

```text
8 - 8 = 0
```

В результате:

```text
13 = 1 + 4 + 8
```

Следовательно, программа действительно раскладывает число на сумму степеней двойки.

# Дополнительное задание 5 **(5)**

*Ответьте на вопросы по программе "Упаковка коротких чисел" из лекции.*

- *Можно ли указанным способом сохранить более 8 чисел? Обоснуйте ответ.*
- *Сколько чисел можно будет сохранить при изменении диапазона от 0 до 7? Обоснуйте ответ.*
- *В чем смысл <<магической>> константы 15 в тексте программы?*
- *Если по условию задачи надо будет сохранить только числа в интервале от 0 до 10, то следует ли заменить эту константу на 10? Обоснуйте ответ.*

## Решение

Изначально программа хранит числа из диапазона:

```text
0 ... 15
```

Максимальное число:

```text
15 = 1111₂
```

Следовательно, для одного числа необходимо четыре бита.

Восемь чисел занимают:

```text
8 * 4 = 32 бита
```

---

### 1. Можно ли сохранить более 8 чисел?

При использовании 32-битной переменной:

```text
32 / 4 = 8
```

То есть помещается ровно восемь четырехбитных чисел.

Для девяти чисел потребовалось бы:

```text
9 * 4 = 36 бит
```

Следовательно, сохранить больше восьми чисел таким способом в одной 32-битной переменной нельзя.

---

### 2. Сколько чисел можно сохранить при диапазоне от `0` до `7`?

Максимальное значение:

```text
7 = 111₂
```

Для одного числа достаточно трех бит.

Вычислим:

```text
10 * 3 = 30 бит
```

```text
11 * 3 = 33 бита
```

Следовательно, в 32-битной переменной можно сохранить:

```text
10 чисел
```

При этом останутся два свободных бита.

---

### 3. В чем смысл константы `15`?
10:25
В программе используется выражение:

```cpp
v & 15
```

Число `15` в двоичной системе:

```text
15 = 1111₂
```

В 32-битном виде:

```text
00000000 00000000 00000000 00001111
```

Эта константа является маской, оставляющей только четыре младших бита числа `v`.

Например:

```text
xxxxxxxx xxxxxxxx xxxxxxxx 1011
00000000 00000000 00000000 1111
--------------------------------
00000000 00000000 00000000 1011
```

Поэтому:

```text
15 = 2⁴ - 1
```

используется как маска четырех младших битов.

---

### 4. Нужно ли заменить `15` на `10`, если числа находятся в диапазоне `0..10`?

Нет.

Число `10` в двоичной системе:

```text
10 = 1010₂
```

Если использовать:

```cpp
v & 10
```

часть битов будет потеряна.

Например:

```text
7 = 0111
```

```text
0111
1010
----
0010
```

Получили:

```text
2
```

вместо `7`.

Для представления чисел из диапазона:

```text
0 ... 10
```

все равно необходимо четыре бита, поскольку:

```text
10 = 1010₂
```

занимает четыре разряда.

Следовательно, маска должна оставаться:

```text
1111₂ = 15
```

Константу `15` заменять на `10` нельзя.

# Дополнительное задание 6 **(3)**

*Рассмотрим следующую программу на языке Python. Сколько чисел она выводит в зависимости от введенного значения* **x**? *Как полученные числа зависят от* **x**?

```python
x = int(input())
i = x
while i > 0:
   print(i)
   i = (i - 1) & x
```

## Решение

Программа перебирает все ненулевые подмаски числа `x`.

Подмаской называется число, единичные биты которого находятся только на тех позициях, где единицы есть у исходного числа `x`.

Рассмотрим пример:

```text
x = 13
```

Двоичная запись:

```text
13 = 1101₂
```

Работа программы:

```text
13 = 1101
12 = 1100
 9 = 1001
 8 = 1000
 5 = 0101
 4 = 0100
 1 = 0001
```

Программа выведет:

```text
13
12
9
8
5
4
1
```

Все эти числа имеют единицы только на тех позициях, где единицы присутствуют в числе:

```text
1101
```

Выражение:

```python
(i - 1) & x
```

получает следующую меньшую подмаску.

Операция:

```text
& x
```

обнуляет все биты, которых нет в исходном `x`.

---

Пусть в двоичной записи числа `x` имеется `k` единичных битов.

Каждый из них может находиться в двух состояниях:

```text
0 — бит не входит в подмаску
1 — бит входит в подмаску
```

Следовательно, общее количество подмасок:

```text
2^k
```

Одной из них является:

```text
0
```

Но ноль не выводится, так как условие цикла:

```python
while i > 0:
```

становится ложным.

Следовательно, для положительного `x` количество выведенных чисел:

```text
2^k - 1
```

где `k` — количество единиц в двоичной записи `x`.

Для примера:

```text
x = 13 = 1101₂
```

Количество единиц:

```text
k = 3
```

Значит программа выведет:

```text
2³ - 1 = 7
```

чисел.

Если:

```text
x = 0
```

программа не выведет ни одного числа.

Если `x < 0`, условие:

```python
i > 0
```

также сразу ложно.

Таким образом, для положительного `x` программа выводит все ненулевые подмаски числа `x` в порядке убывания, а их количество равно:

```text
2^k - 1
```

где `k` — число единичных битов в двоичной записи `x`.
